##Trabalho de Criptografia PGM ASCII

1. Objetivo

Implementar e analisar duas técnicas didáticas de criptografia aplicadas a imagens em tons de cinza no formato PGM ASCII(P2).

2. Técnicas implementadas

- **ECB:** processamento dos pixels em blocos de 8, utilizando XOR e uma chave estática.
- **Stream Cipher:** processamento individual dos pixels, utilizando XOR com valores pseudoaleatórios.
